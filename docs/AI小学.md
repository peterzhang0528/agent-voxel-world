# AI 小学

在 [peterzhang0528/agent-voxel-world](https://github.com/peterzhang0528/agent-voxel-world) 上的训练营式实验：每人一块地盘，再加一个会把气氛带起来的专属 AI 伙伴。这是 fork 自己的 MVP，不往上游 `lulabs-org/agent-voxel-world` 合并。

## 本地运行

```sh
pnpm install
pnpm dev
```

浏览器打开 http://127.0.0.1:5173 。不配置 `DATABASE_URL` 时，服务端会明确进入内存模式：规则和围栏都在，重启后认领会丢，方块编辑也不保留。配置了数据库但连不上时，仍然会启动失败，不会偷偷改成内存模式。

`pnpm dev` 同时启动 Colyseus（`127.0.0.1:2567`）和 Vite。不需要先跑 `pnpm agent:ai`，伙伴由房间在认领后自己拉起来。

## 怎么认领地

1. 在大厅输入昵称，进入世界。
2. 服务器按进房顺序分配 16 块里的空地，并用昵称记住。同一进程里再次用这个昵称进入，还是原来那块。
3. 左上角出现「地盘 A1」这类编号，人物出生在围栏内侧。
4. 16 块分完后，新的昵称会在大厅看到「今天的地盘已经分完了」。

地盘是 4×4，每块 5×5，落在地形 `-12…12`（约 25×25）里面，彼此不重叠。中间和地块之间是公共走道。

## 建造权限

服务器在原有距离、支撑、基岩和版本校验之后再查领地，前端拦不住。

| 位置             | 谁可以改                       |
| ---------------- | ------------------------------ |
| 自己地盘围栏内侧 | 主人，以及绑定在这块地上的伙伴 |
| 围栏所在的整列   | 谁都不行，避免边界被拆掉       |
| 公共走道         | 只读，不能放也不能挖           |
| 还没人认的地盘   | 只读                           |

挖别人的地盘会被拒绝。离得太远时，仍会先返回原来的「够不着」。

## 怎么看到伙伴在带节奏

认领后几秒内，伙伴出生在同一块地里，名字类似 `A1·你的昵称`，身份是 `ai-agent`。它复用 `@voxel/agent-runtime` 的世界会话：观察、朝角落走几步、放第一块木头、在群聊里说话。不需要模型 API Key。

演示时看这三处：

1. **左上角广播**：进世界后会滚出最近几句群聊。第一句是「同学们好呀」，接着 `@你的昵称` 布置「来帮我搭这个角」，再喊路过的同学来看。
2. **围栏内侧的第一块木头**：伙伴先放下，任务就是让你在旁边再补一块。木头在橙色围栏里面，不是在走道上。
3. **之后大约每 22 秒一句**：轮流喊同学、鼓励你、约你去走道逛一圈再回来搭。你在聊天里说话，伙伴大约 8 秒内会回一句给气氛加热，但不会每条都抢答。

聊天面板收起时也能看到未读。点开后是完整群聊。伙伴不会私聊刷屏，这些带动都在公共频道。

控制台里另行创建的模型 Agent 仍然走原来的 Pi 循环。角色设定留空时，系统提示词和角色上下文会用同一套「热情的 AI 小学同学」人格：中文、会起哄、会鼓励、会主动提议一起搭或一起逛。模型要自己的 API Key 才会说话；领地伙伴不依赖它。

## 和上游的差异

- 上游是单世界共享建造，谁够得着谁就能改。这里改成校园格子。
- 上游没有「一个玩家绑定一个 Agent」。这里人类进房就生成伙伴，出生在自己的地盘里。
- 伙伴会主动开场和跟进，不是只等你说话。
- 房间容量从 16 调到 32，给 16 个主人和 16 个伙伴留座位。
- 围栏是新的 `fence` 材质（橙色），不能当建造材料选进快捷栏。
- 认领关系只活在房间内存里。数据库若开着，记住的是方块，不是主人。

## 已知限制

- 没有账号。昵称相同就视为同一个人；进程重启后认领清空，内存模式下方块也清空。
- 离开世界不会立刻腾出地盘，这个昵称回来还能进。分完 16 块才会拒绝新人。
- 伙伴是固定剧本加观察/移动/放置，不是完整的任务规划循环。它不会给你盖一整栋房子。
- 围栏高一格，角落两格，可以跳出去串门，但不能改别人的地，也不能拆围栏。
- 公共走道和未认领地都是只读，不是「只能看不能进」。
- 不做背包、战斗、英语积分。
- 控制台 Agent 仍受原来的「最多 4 个在线托管角色」限制。领地伙伴不占这 4 个名额，但占世界座位。
